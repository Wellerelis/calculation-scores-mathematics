# Калькулятор баллов — Высшая математика

Интерактивный веб-калькулятор для расчёта итоговых баллов по дисциплине **Высшая математика**, Лагунова М.В., 1 курс, 2 семестр.

**[→ Открыть калькулятор](https://wellerelis.github.io/calculation-scores-mathematics/index.html)**

---

## Что делает калькулятор

Вы вводите полученные баллы по каждому элементу оценивания — калькулятор автоматически:

- **Считает процент выполнения** по каждому элементу с цветовой индикацией (зелёный ≥ 75%, жёлтый ≥ 50%, красный < 50%)
- **Рассчитывает вклад в итог** — сколько процентов от финального балла даёт каждый компонент
- **Суммирует блоки ТК-1, ТК-2, ИД, ПА** с прогресс-барами по каждому разделу
- **Выводит итоговую оценку** (2–5) с порогами 85% / 70% / 55%
- **Обновляется в реальном времени** — без кнопки «Рассчитать», сразу при вводе
- **Работает офлайн** — единый HTML-файл, не требует сервера или установки

Незаполненные поля отображаются как «—» и не учитываются в расчёте — можно прогнозировать оценку на любом этапе семестра.

## Формулы расчёта

### Вклад каждого элемента

```
вклад = (балл / макс_балл) × вес_в_блоке × вес_блока_в_итоге
```

Примеры:

```
c_коллоквиум = (koll / 30) × 0.75 × 0.40 × 0.80
c_экзамен    = (exam / 45) × 0.75 × 0.60 × 0.80
c_доп1       = (d1   / 10) × 0.2273 × 0.20
c_па         = (oral / 10) × 1.00   × 0.20
```

### Итоговый результат

```
итог_% = сумма всех вкладов × 100
итог_баллов = итог_% / 100 × 144
```

## Как пользоваться

### 1. Параметры — не требуются

Все весовые коэффициенты жёстко заданы под конкретный курс. Ничего настраивать не нужно.

### 2. Ввод баллов

Введите полученные баллы в соответствующие поля:

| Секция | Поля | Диапазон |
|--------|------|----------|
| ТК-1 | Раздел 6, Коллоквиум | 0–10, 0–30 |
| ТК-2 | Р7, Р8, Р1п, Экзамен | 0–5, 0–5, 0–5, 0–45 |
| ИД | Доп 1–5 | 0–10, 0–10, 0–4, 0–10, 0–10 |
| ПА | Устный ответ | 0–10 |

Поля принимают дробные значения (шаг 0,01).

### 3. Итоговая панель

После ввода хотя бы одного значения внизу страницы появляется итоговая панель:
- суммарный балл (из 144) и итоговый процент
- предполагаемая оценка с расшифровкой
- разбивка вклада по блокам: ТК, ИД, ПА

### 4. Мобильная версия

На экранах ≤ 700 px таблицы заменяются карточками с крупными полями ввода — удобно заполнять прямо с телефона после получения результата.

## Известные ограничения

- Веса элементов оценивания захардкожены под конкретный курс и семестр — при изменении системы оценивания потребуется правка кода
- Все баллы считаются независимыми; пересдача или бонусные баллы отдельно не предусмотрены
- Блок «ПА — Промежуточная аттестация» помечен как дополнительный (доп. балл) — уточняйте условия у преподавателя
